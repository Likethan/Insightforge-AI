### II. Layout Details:

The UI follows a classic three-column layout, common in web applications.

1.  **Left Sidebar (Fixed Width):**
    *   Contains the platform branding, navigation for sessions/history, and global settings.
    *   Sections are clearly delineated with headers ("History," "Settings").
    *   "History" and "Settings" appear to be `st.expander`-like components, allowing them to be collapsed/expanded, though they are currently expanded.
    *   Buttons for "New Research Session" and "Export All Settings" are prominently displayed with gradient colors.

2.  **Central Content Area (Dynamic Width):**
    *   This is the primary interaction area.
    *   Starts with a prominent "Research Dashboard" title.
    *   Followed by a `st.text_input` for the research topic, with action buttons ("Start Research," "Advanced Options") below it.
    *   A status section ("Current Phase") with a `st.progress` bar and control buttons ("Pause," "Cancel").
    *   A "Multi-Agent Team Status" section, which displays a `st.success`-like message and individual agent statuses (like the "Supervisor" card).
    *   Includes a "View Agent Logs" link.

3.  **Right Report Preview Area (Fixed/Dynamic Width):**
    *   A dedicated section for displaying the generated research report in real-time.
    *   Clearly titled "Live Report Preview."
    *   The report content is structured with headers (e.g., "1. Executive Summary," "2. Yield Projections").
    *   Includes text paragraphs and a partially visible chart, suggesting `st.write` and `st.image` or chart components are used.

**Overall Design:** The interface uses a dark mode theme with good contrast. Interactive elements like buttons and selectboxes have distinct visual cues. Icons (emojis) are effectively used to enhance readability and categorize sections.
